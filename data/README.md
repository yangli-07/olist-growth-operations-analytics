# Data

## Source

Brazilian E-Commerce Public Dataset by Olist:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Raw Data

The raw dataset contains nine CSV files covering orders, customers, products,
sellers, payments, reviews, order items, product category translations and
geolocation data.

Raw CSV files are stored locally in `data/raw/` and are excluded from Git.

## Processing Rule

Raw files must not be edited directly. Any cleaned or transformed datasets
will be saved in `data/processed/`.
